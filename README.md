# 🚕 Uber Reviews Sentiment Analysis Dashboard

Proyek ini melakukan analisis sentimen pada ulasan pengguna Uber. Tujuan dari proyek ini adalah memahami persepsi pelanggan terhadap layanan Uber melalui visualisasi data, analisis kata, dan tren waktu.

---

## 📁 Dataset
Dataset berisi ulasan pengguna Uber dan informasi seperti:
- `review`: Isi ulasan pelanggan
- `score`: Rating dari 1–5
- `at`: Timestamp kapan ulasan diberikan
- `sentiment`: Kategori sentimen hasil klasifikasi (positive, neutral, negative)
- `month_year`: Kolom hasil ekstraksi bulan & tahun dari timestamp `at`

---

## 🔍 Fitur Analisis

### 📊 1. Distribusi Sentimen
Menampilkan pie chart jumlah review berdasarkan kategori sentimen.

### 📈 2. Tren Sentimen dari Waktu ke Waktu
Visualisasi perubahan jumlah review positif, netral, dan negatif dari bulan ke bulan.

### ☁️ 3. Wordcloud per Sentimen
Wordcloud untuk melihat kata-kata yang paling sering muncul dalam review positif, netral, atau negatif.
